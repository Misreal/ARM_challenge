Any CIFAR-100 model with a 32×32 input

The importer checks the graph, builds the quantization-ready variant, recovers the block structure sensitivity analysis reads, and scores the FP32 baseline. Then the same pipeline runs on it.

python -m src.import_onnx --onnx yours.onnx --name yours --seal-test
python -m src.app run --model yours

Needs a static 1×3×32×32 input, 100 classes, opset 13 or later, and nodes carrying module paths — a normal PyTorch export has all four. The second command measures on a Raspberry Pi, so it needs one configured in pi_target.json.
